Política de Privacidade

Última atualização: 23 de outubro de 2026

O que é o autocanal

O autocanal é uma ferramenta de uso pessoal, executada apenas no computador da sua responsável, que cria vídeos e os publica nos canais do YouTube dela. Ele usa os Serviços de API do YouTube.

Quais dados são acessados

Com a autorização dada na tela de login do Google, o autocanal acessa somente o canal da própria responsável, para:

  • enviar vídeos e agendar a publicação (permissão youtube.upload);
  • consultar o status de processamento e alterar a privacidade dos próprios vídeos (permissão youtube);
  • ler estatísticas dos próprios vídeos, como visualizações e tempo assistido (permissão yt-analytics.readonly).

O autocanal não coleta dados de espectadores nem de qualquer outra pessoa.

Como os dados são guardados

A credencial de acesso e as estatísticas ficam armazenadas apenas no computador da responsável, em arquivos de acesso restrito. Não existe servidor do autocanal: nenhum dado é enviado, vendido ou compartilhado com terceiros.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

YouTube e Google

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Consulte também a Política de Privacidade do Google.

Como revogar o acesso e apagar os dados

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google. Os dados locais podem ser apagados a qualquer momento, removendo os arquivos do autocanal do computador.
