autocanal

Ferramenta pessoal de produção de vídeos

O autocanal é uma ferramenta de uso pessoal que roda no computador da sua responsável. Ele ajuda a criar vídeos e a publicá-los nos canais do YouTube dela, usando os Serviços de API do YouTube.

O aplicativo não é oferecido ao público, não tem contas de usuário e não acessa canais de outras pessoas.
