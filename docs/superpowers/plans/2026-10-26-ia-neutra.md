# Núcleo de IA independente de provedor (Claude + Codex): plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** trocar `autocanal/claude.py` por um pacote `autocanal/ia/` com capacidades neutras e adaptadores do Claude Code e do Codex, escolhidos por etapa na config.

**Architecture:** cada etapa monta um `ia.Pedido` (prompt, schema, pasta, web, imagens, métodos, scripts) e chama `ia.chamar(cfg, con, job_id, etapa, pedido)`. O núcleo escolhe o provedor pela config, checa a pausa do provedor, copia as skills para `<pasta>/metodo/`, chama o adaptador e registra o uso em `chamadas_ia`. As pausas por limite ou indisponibilidade são gravadas por provedor, só dentro de `ia.chamar`.

**Tech Stack:** Python 3.12, pydantic, jsonschema, sqlite3, pytest; CLIs `claude` e `codex`.

**Spec:** `docs/superpowers/specs/2026-10-26-ia-neutra-design.md`

## Global Constraints

- Testes: `/home/losawa/.local/share/autocanal-tools/bin/uv run pytest -q` (o `uv` não está no PATH). Nos comandos abaixo, `UV` = esse caminho.
- Etapas de IA (chaves na config e em `chamadas_ia`): `roteiro`, `curadoria`, `metadados`, `revisao`, `temas`.
- Quem chama usa `from autocanal import ia` e `ia.Pedido`, nunca `from autocanal.ia import Pedido`: `provedores/imagens.py` já tem uma classe `Pedido`.
- Pausa de provedor: 1 h, em `dados/pausa_ia/<provedor>`; 1ª linha com o fim em ISO UTC, 2ª com o motivo. O motivo do limite é exatamente `limite de uso`.
- Bloco antigo recusado com a mensagem exata: "o bloco `claude:` virou `ia:`; veja `config/autocanal.yaml`".
- Valor padrão de `max_turns` quando a etapa não está na config: 20.
- Custo nulo aparece como "—" no resumo, nunca "US$ 0.00".
- Nunca ler, imprimir nem tocar `config/segredos.env`, `config/client_secret.json` e `dados/tokens/`. Nunca rodar `publicar`, `vetar`, `auth` nem `instalar-timer`.
- Testes marcados `real` e produção de jobs de verdade só com o ok de Laura.
- Código, nomes, docstrings e mensagens em português, no estilo dos módulos vizinhos.
